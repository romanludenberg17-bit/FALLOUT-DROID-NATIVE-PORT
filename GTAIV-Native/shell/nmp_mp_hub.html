  • Игра сначала загрузит сюжет — так устроена GTA IV: мультиплеер открывается из телефона Нико (телефон → Мультиплеер).
  • Хост жмёт «Я хост», в игре: телефон → Мультиплеер → кооп-миссия → создать.
  • Второй игрок жмёт «Найти по Wi-Fi» и выбирает игру хоста в списке.
  • Через VPN (ZeroTier/Tailscale/Radmin) оба игрока вписывают свой VPN-IP в «Мой IP VPN», второй — «Подключиться по IP» с VPN-IP хоста. Если в Wi-Fi игра не видна — «Подключиться по IP». IP хоста: Настройки → Wi-Fi → сеть → IP-адрес (у точки доступа обычно 192.168.43.1).
